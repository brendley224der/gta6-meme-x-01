still waiting by their car in neon Vice City after 13 years — while the
make.fun ghost, riding along with its magenta star coin, got paid on
make.fun. The meme is posted on X from a public account; `POST.json` holds
the post's address and `main.ts` copies it to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
